# Issue #3: 支持用户输入数字来指定长度，k 应该指 1024

## 问题
1. `--targets` 只支持纯数字，不支持 `32k` 这种简写
2. 文件名标签里 `k` 用的是 1000（`32000 // 1000 = 32k`），应该用 1024

## 方案
- `--targets` 解析支持 `k`/`K` 后缀，按 ×1024 计算：`32k` → 32768，`64k` → 65536
- 也支持纯数字：`32768`、`200000`
- 混合使用：`4k,32768,64k,100000`
- 文件名标签改用 1024：`32768 // 1024 = 32k`
- 默认值更新：`4k,16k,32k,64k,200k`

## 改动
- `build_testdata.py` 新增 `_parse_target(s)` 函数
- 修改 `label` 计算逻辑：`// 1000` → `// 1024`
- 更新 `--targets` 默认值
- 更新 README 文档
